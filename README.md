# Omar Walaa Hassan Sayed Abdelsalam — Portfolio

Professional portfolio for a Railway Engineering student in Egypt. The page presents railway systems training, technical skills, education and contact information.

The site is a static HTML, CSS and JavaScript page. Profile photographs are stored in `assets/`, the hero background is `Back.jpg`, and the electric train model image is in `assets/projects/`.

## Publish

Import the repository into Vercel using the **Other** framework preset. No build command is required; the included `vercel.json` sets the project root as the output directory.
